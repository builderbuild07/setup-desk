Method

How we test

  1. Start the timer at the start

    From the moment we accept or start the job, not when the action begins. Travel counts.

  2. Run it three times

    We use the average payout and average time, so one lucky run doesn't skew the table.

  3. Work out $ per hour

    Average payout divided by average minutes, times 60.

  4. Date it

    Rockstar changes payouts in patches. Every row shows when we tested it, and we retest after big updates.

What counts

Only methods we've timed ourselves on a retail copy. No glitches or exploits that could get your account flagged.
